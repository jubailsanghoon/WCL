🚀 표준 앱 헤더 컴포넌트 킷 (App Header Component Kit)

이 페이지는 다른 모든 웹앱(예: HeatInput23, 계측기 앱, 계산 도구 등)에 즉시 복사하여 사용할 수 있도록 독립 구성된 표준 네비게이션 헤더입니다.

📦 간편 복사 및 연동 방법 (Quick Start)

다른 프로젝트에 이 헤더를 넣으려면 아래 3개 파일만 포함하면 됩니다:

<!-- 1. CSS 로드 --> <link rel="stylesheet" href="header-kit.css" /> <!-- 2. HTML 헤더 마크업 붙여넣기 (위 index.html 코드 참조) --> <!-- 3. JS 초기화 --> <script src="header-kit.js"></script> <script> HeaderKit.init({ version: "v1.0", isPro: false, defaultLang: "ko", onThemeChange: (theme) => console.log("Theme:", theme), onLanguageChange: (lang) => console.log("Language:", lang), onLicenseClick: (isPro) => alert(isPro ? "PRO 라이선스 관리" : "PRO 라이선스 업그레이드"), onHelpClick: () => document.getElementById("helpModal").classList.remove("hidden") }); </script>
📖 도움말 및 가이드

헤더의 [📖] 버튼을 누르면 열리는 표준 모달 창 샘플입니다.

각 앱의 용도에 맞게 매뉴얼, 라이선스 안내, 버전 릴리즈 노트를 출력할 수 있습니다.
