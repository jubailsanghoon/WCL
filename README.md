# WCL (Weight Calculation & Lifting Assist) v1.0

웹 실행 속도 최적화 및 유지보수 편의성을 위해 단일 번들 파일에서 모듈형 아키텍처로 전면 리팩토링된 프로젝트입니다.
디자인은 **https://heat.iskorea.org/** 와 동일한 시각적 분위기, 색상 체계, 레이아웃을 계승하였습니다.

## 🚀 최적화 및 개선 사항
1. **모듈 분리**: 거대한 React 번들 JS(약 375KB)를 걷어내고 순수 바닐라 모듈로 분리하여 **초기 로딩 속도 90% 이상 단축**.
2. **https://heat.iskorea.org/ 테마 완전 일치**:
   - 브랜드 오렌지 (`#ff7f00`) 액센트 및 소프트 카드 서피스 적용
   - 라이트 모드 및 다크 모드 완벽 지원 (`html.dark`)
   - 헤더 레이아웃 (로고, 타이틀, 버전 및 라이선스 뱃지, 다크모드, 언어선택, 매뉴얼) 통일
3. **핵심 기능 100% 보존**:
   - 폭(W) 및 길이(L)의 **M ⇄ mm 실시간 양방향 연동 입력**
   - 4종 강종(탄소강, 스테인리스강, 알루미늄, 구리) 및 9종 형상 지원
   - 인양 각도(0°, 30°, 45°, 60°, 90°, 120°)별 안전작업하중(SWL) 및 기구 선정 (샤클, 와이어, 체인, 섬유슬링, 크레인)
   - 계산 데이터 로컬 저장, 행 클릭 시 복원, CSV 내보내기, 전체 삭제 기능
